## 开发约定

1. 从 `main` 分支切出功能分支开发，分支命名建议 `feat/<简述>`、`fix/<简述>`。
2. 提交信息保持简洁明确，说明改动目的。
3. 通过 Pull Request 合并，合并前完成自测并补充相应文档。

## 贡献指南

1. Fork 或直接在本仓库创建分支。
2. 提交改动并发起 Pull Request，描述背景、改动点与验证方式。
3. 由维护者 Review 后合并。
